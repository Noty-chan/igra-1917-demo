# Демо на GitHub Pages

Демо публикуется из каталога `dist` репозитория `Noty-chan/igra-1917-demo`. Workflow `.github/workflows/pages.yml` запускается после каждого push в `main` или вручную через вкладку Actions.

Адрес сайта: <https://noty-chan.github.io/igra-1917-demo/>.

## Вход

Страница входа проверяет пару логин/пароль в `dist/core/access.js`. Для этой демо-версии логин и пароль находятся в клиентском JavaScript. Это только экран от случайного просмотра: посетитель может прочитать файлы репозитория или изменить проверку в браузере. GitHub Pages не предоставляет серверную авторизацию для этого статического сайта.

Не переиспользуйте этот пароль. Не используйте опубликованную демо-версию для настоящих игровых секретов, учётных записей или совместного состояния. Изменения ведущего и игрока сохраняются только в браузере того, кто их сделал.

Чтобы сменить пароль, поправьте `DEMO_USERNAME` и `DEMO_PASSWORD` в `dist/core/access.js`, проверьте `npm test` и отправьте изменения в `main`. Новый вход станет активен после завершения workflow Pages.

## Настройка публикации

В GitHub откройте **Settings → Pages** и выберите **GitHub Actions** как источник сборки, если настройка ещё не выбрана. Затем запустите workflow **Deploy game preview** в Actions или отправьте commit в `main`.

Локальный файл `ACCESS-CREDENTIALS.local.txt` хранит копию выданного входа для владельца. Он исключён из Git и не должен добавляться в commit.
