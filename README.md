# ИГРА — усадебный ваншот

Рабочая демо-версия сайта игры «ИГРА» по Vampire: The Masquerade Revised. Материалы подготовлены по предоставленным листам персонажей и документу с правилами и целями.

## Демо

Сайт доступен по адресу <https://noty-chan.github.io/igra-1917-demo/>. Логин и пароль для клиента передаются отдельно; они не менялись в обновлении от 5 октября.

Последние правки: новые портреты и варианты смерти, ростер 3×3, исправленные натуры/маски и секты, общий лист ресурсов, повреждения, журнал бросков с волей и комментариями, события и памятка игрокам. Полный список — [CLIENT-CHANGES-2026-10-05.md](CLIENT-CHANGES-2026-10-05.md).

Ведущий может проверять ростер и раскрытия, а игрок — закрепить персонажа и посмотреть личный лист. Состояние сохраняется только в браузере.

## Проверки и публикация

Запустите `npm test`. Инструкции по GitHub Pages и парольному экрану находятся в [DEPLOY.md](DEPLOY.md); содержание и правила подготовки — в [PROJECT-NOTES.md](PROJECT-NOTES.md) и [CONTENT-GUIDE.md](CONTENT-GUIDE.md).

Парольный экран — только удобный барьер для просмотра. GitHub Pages отдаёт статические файлы; логин и пароль видны в коде. Состояние и журнал обновляются между вкладками одного браузера, но не между устройствами. Не использовать сайт как защищённую игровую систему.
